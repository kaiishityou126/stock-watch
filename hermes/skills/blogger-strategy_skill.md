# 微博大 V 投资策略提炼

工作目录即 stock-watch 仓库根目录。数据已由 cron 抓取入库,本技能只读,**固定两步**。

> **铁律(优先级最高,覆盖本文件其余一切):整个流程只有两步——第 1 步执行下方唯一的读取命令,第 2 步基于它的 JSON 输出直接写出报告作为最终回复。除此之外什么都不做:不要 cat config.json、不要自己写 SQL、不要探查表结构、不要运行任何第二条命令、读取报错也不要换参数重试。你的最终回复必须就是报告正文本身,输出完立即结束,同一轮里不要再追加任何内容。回答末尾固定加一行 `(BOT)`,这是本技能输出的标志,绝不能省略。**

## 第 1 步:读取博文数据(仅此一条命令)

```
python -m report.reader --groups weibo_posts
```

- 自动按 `config.json` 的 bloggers 清单逐人读取,每人最新 200 篇博文,无需传其他参数。
- 输出纯 JSON:`weibo_posts` 列表,每行为
  `{uid, user_name, text, reposts_count, comments_count, attitudes_count, created_bj}`,
  其中 `created_bj` 是发布时间(北京时),`uid` 相同的行属于同一位博主。
- 若输出含 `error` 字段:把错误内容原样转述给用户即可结束,不要调试、不要重试。
- 某位博主没有数据就是没有,如实说明,不要编造。

## 第 2 步:提炼投资策略并直接输出

对每位博主,从博文中提取:

1. **核心风格** — 短线/中长线/价值/成长/题材/量化?一句话概括
2. **关注赛道** — 常提的行业/板块(如半导体、新能源、消费)
3. **典型手法** — 选股逻辑、买卖时机、仓位管理
4. **近期观点** — 最近在看什么、怎么看
5. **可信度信号** — 是否有实盘验证/逻辑一致性/事后复盘

输出格式(你的最终回复就是这个正文):

```
## 博主 A(基于 N 条博文,时间跨度 YYYY.MM.DD–YYYY.MM.DD)

- 风格: ...
- 赛道: ...
- 手法: ...
- 近期: ...
- 可信度: ...

## 博主 B
...
```

`N` 取该博主(uid 相同)的行数;时间跨度取该博主 `created_bj` 的最早与最晚日期。

**规则:**
- 只从博文原文归纳,不编造
- 不搬运原文,只出加工结论
- 不评判对错,不推荐跟单
- 标注信息来源的时间跨度
- 明确声明"仅供参考,不构成投资建议"
