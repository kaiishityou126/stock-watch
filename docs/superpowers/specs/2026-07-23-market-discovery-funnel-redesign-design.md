# market 重设计:自顶向下「资金 + 情绪」发现漏斗

- 日期:2026-07-23
- 状态:已与用户对齐(纯讨论定稿),待评审 → 计划 → 实现
- 关联:重设计 `market` 包的**数据层**,为未来「主动点名 板块 + 个股」的每日简报打地基。本文档只定**存什么数据、几张表、字段口径**,不写实现代码。

## 1. 背景与动机

现状 `market` 包只有两张表(见 [market/storage.py](../../../market/storage.py)):

- `market_snapshot`:按 `(trade_date, sector)` 存板块级 `pct_change` / `turnover` / `volume` + 近似口径 `main_net_inflow_est`(主力=超大+大单)/ `retail_net_inflow_est`(散户=中+小单)。
- `dragon_tiger`:龙虎榜,按 `(trade_date, stock_code, reason)` 去重,`inst_seat_count` 机构席位数。

问题:当前设计只是「板块资金流 + 龙虎榜」两张孤立快照,**没有服务于一个明确的分析目标**。用户的真实诉求(本轮澄清)是——系统不是自动下单,而是产出一份**主动发现**的每日简报:自顶向下,从大盘 → 情绪 → 主线板块 → 板块内个股,层层收窄,最终**点名值得关注的板块和个股**(带资金关注度)。

要支撑这个「发现漏斗」,行情数据层需要重设计:补齐大盘指数层、市场情绪层,扩展板块资金流口径,并明确哪些数据**现在不做**(避免过度工程)。

## 2. 目标与非目标

**目标**
- 定下行情层最终 **3 张表**的字段口径:`index_snapshot`(大盘)、`market_sentiment`(情绪)、`market_snapshot`(板块,扩展)。
- 明确「自顶向下发现漏斗」四环与三张表的对应关系。
- 明确一期**落地范围**与**明确不做**的边界(诚实对齐 A 股免费数据的可得性约束)。
- 全部数据按 `trade_date` 日快照存 → 天然时间序列(供后续算环比 / 加速 / 反向)。

**非目标**
- 不写实现代码(本文档纯设计;实现走后续「计划 → 实现」)。
- 不做个股级抓取(漏斗 ④,未来期;本期连表都不建)。
- 不做集中度 / 北向资金 / K线 / 筹码 / 财报 / 回测(理由见 §6)。
- 不改微博 / 雪球 / report / notify 的既有行为。
- 不做 git 提交(当前非 git 仓库)。

## 3. 自顶向下发现漏斗

```
① 大盘走势         index_snapshot        —— 今天是进攻还是防守日?
      ↓
② 市场情绪         market_sentiment      —— 硬指标腿(涨跌停/成交额)
   + 舆情文本      (微博/雪球)            + 文本腿(人嘴上多兴奋),两腿背离最有信号
      ↓
③ 主线板块         market_snapshot       —— 板块级信号识别:谁在被资金持续关注
      ↓
④ 板块内个股       (未来·stock_fund_flow) —— 只对主线板块成分股拉,不全市场普查
      ↓
   《每日观察简报》 主动点名 板块 + 个股
```

**核心原则**
- 全部按 `trade_date` 日快照存,攒多日成时间序列(集中度加速 / 资金波浪 / 情绪反向 / 环比全靠历史对比)。
- LLM 只吃**确定性数据**(表里算好的结构化指标),不读原始数据自己现算,不臆测。
- 「主线板块」是**分析产出的结论**,不是存储的子集——`market_snapshot` 每天存**全量**行业 + 概念板块,主线由下游按信号筛出。

## 4. 三张表字段口径

### 4.1 `index_snapshot`(大盘指数,新表)服务漏斗 ①

| 字段 | 含义 | 备注 |
|---|---|---|
| `trade_date` | 交易日 | 主键之一 |
| `index_code` | 指数代码 | 主键之一 |
| `index_name` | 指数名 | —— |
| `close` | 收盘点位 | —— |
| `pct_change` | 涨跌幅 | —— |
| `turnover` | 成交额 | 仅 A 股三大指数有;海外为 NULL |
| `volume` | 成交量 | 仅 A 股三大指数有;海外为 NULL |
| `source` / `fetched_at` | 溯源 | —— |
| 主键 | `(trade_date, index_code)` | —— |

- **A 股三大指数**(存 收 / 涨跌 / 额 / 量):上证综指 `sh000001`、深证成指 `sz399001`、创业板指 `sz399006`。
- **海外六指数**(只存 收 / 涨跌,`turnover`/`volume` = NULL):恒生、道指、纳指、标普、日经、韩国 KOSPI。
- ⚠️ 时区提醒:美股 / 欧股是**隔夜收盘**,与当日 A 股不同步;简报里要标注口径,别当同日信号误读。

### 4.2 `market_sentiment`(市场情绪 / 宽度,新表)服务漏斗 ②(硬指标腿)

| 字段 | 含义 | 为什么要 |
|---|---|---|
| `trade_date` | 交易日(主键,一天一行) | —— |
| `up_count` | 上涨家数 | 赚钱效应 |
| `down_count` | 下跌家数 | 亏钱效应 |
| `limit_up_count` | 涨停家数 | 情绪高潮 / 退潮 |
| `limit_down_count` | 跌停家数 | 恐慌 |
| `up_down_ratio` | 涨跌家数比(`up/down`) | 一眼看多空 |
| `total_turnover` | 全市场成交额 | 算分位(放量 / 缩量) |
| `margin_balance` | 两融余额 | 杠杆情绪(慢变量,T+1) |
| `fetched_at` | 溯源 | —— |

- akshare 可得性:家数 / 涨跌停 / 活跃度用 `stock_market_activity_legu`(乐咕乐股-赚钱效应)**一次调用**直接返回,不用遍历个股;成交额走市场总貌 / 指数;两融走 `stock_margin_*` 系列。
- 与舆情文本腿(微博 / 雪球)并列喂 LLM:一个说「市场客观多热」,一个说「人嘴上多兴奋」,**背离时最有信号**。
- 攒多日 → 情绪反向(涨停家数见顶回落 = 退潮)、成交额分位(今日 vs 近 60 日)。

### 4.3 `market_snapshot`(板块,扩展现有表)服务漏斗 ③

在现有字段基础上**扩展**:

| 字段 | 含义 | 变更 |
|---|---|---|
| `trade_date` | 交易日 | 主键 |
| `sector` | 板块名 | 主键 |
| `sector_type` | `行业` / `概念` | **新增**;两类同表,靠此列区分。主键补入 |
| `pct_change` | 板块涨跌幅 | 保留 |
| `turnover` | 成交额 | 保留(best-effort) |
| `volume` | 成交量 | 保留(best-effort) |
| `super_large_net` | 超大单净额 | **新增**(四级净额拆分) |
| `large_net` | 大单净额 | **新增** |
| `medium_net` | 中单净额 | **新增** |
| `small_net` | 小单净额 | **新增** |
| `main_net_inflow_est` | 主力净额(超大+大) | 保留(合成) |
| `retail_net_inflow_est` | 散户净额(中+小) | 保留(合成) |
| `source` / `fetched_at` | 溯源 | 保留 |
| 主键 | `(trade_date, sector, sector_type)` | **扩展**(原为 `trade_date, sector`) |

- Q2 定案:**行业 + 概念都抓**(全量,~86 行业 + ~300+ 概念),地域丢弃。
- 每天存**全量**板块,不预筛「主线」。

**主线识别(纯板块级,不碰个股)** —— 由下游用 `market_snapshot` 历史快照算:

| 主线信号 | 算法(板块级时间序列) |
|---|---|
| 板块领涨 | 当日 `pct_change` 排名靠前 |
| 资金连续流入 | `main_net_inflow_est` 连续 N 日 > 0 |
| 资金加速 | 主力净额环比放大(今日 vs 昨日 / 近 5 日均值) |
| 资金结构健康 | 超大 + 大单流入**而**中小单流出(主力进、散户没跟风) |

## 5. 一期落地范围

- **落地**:`index_snapshot`(①)、`market_sentiment`(②硬指标腿,含两融)、`market_snapshot`(③扩展)。全板块 / 市场级、低频、合规。
- **既有 `dragon_tiger`**:保留。龙虎榜重定位为「热度验真」——给舆情热股验明正身(游资席位 vs 机构席位),不当预测信号(它是滞后信号,无稳定预测力)。可后续补 `inst_net_buy`(机构席位净买额)真值。

## 6. 明确不做(避免过度工程 / 诚实的数据约束)

| 不做项 | 原因 |
|---|---|
| **集中度**(涨幅前 30% 均值 − 全市场中位数) | 需全市场个股涨幅(虽只 1 次 `stock_zh_a_spot_em` 调用);是市场宽度锦上添花指标,板块级信号已够识别主线。用户拍板先不做 |
| **北向资金每日净流入** | 官方 2024-08-18 起停止实时披露,akshare 相关接口失效 / 仅存档 |
| **`stock_fund_flow` 个股资金流**(漏斗 ④) | 未来期。只对主线板块成分股拉(守低频红线,不全市场普查)。本期**连表都不建**,只记设计 |
| **K 线 / 技术指标 / 筹码集中度 / 股东户数 / 财报 / 回测** | 真·三期(量化选股),超出观察 / 研究定位 |

**诚实的 A 股免费数据约束**(已跟用户对齐并接受):
1. 免费板块资金流只有「净额」,不拆买卖方向、无「量(股数)」;主力 / 散户是按单子大小估的,**非真实身份**。
2. 海外指数 akshare 只有点位 + 涨跌幅,无成交量 / 额。
3. 无干净的每日全市场真实机构 / 散户资金流;仅龙虎榜机构席位 / 大宗交易 / 机构调研是「点状」真机构脚印,且都是个股级。
